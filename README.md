# Screen Free Rewards

Charcoal and gold dashboard for screen-free time. Children earn points for time away from screens. Parents set rewards, schedules, and approve requests.

## Open the app

Open [index.html](index.html) in a browser. No install step. The same file is [screen-free-rewards-final.html](screen-free-rewards-final.html).

## Child

- Start and stop the no-screen timer.
- **Redeem points** spends points on rewards a parent added and sends the request to both parents.
- **Ask parents** sends any request. **Suggest reward** does the same, and an approval adds it to the reward list.

## Parents

Parent PIN defaults to `1234`. In Profile, add both parents' name, email, and mobile, and turn on "both at work". Requests show up immediately under Requests. Approve or decline there. Approving a suggestion adds it to Rewards. Declining a redeem refunds the points.

A downloaded HTML file cannot push notifications by itself. The request is stored in the app at once, and if emails are saved it also opens a message addressed to both parents.
