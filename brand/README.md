# Stellora brand kit

**Company name:** Stellora (star plus aura). **Product:** Screen Free Rewards.
Tagline lockup: `Stellora` over `SCREEN FREE REWARDS`.

> Name check: a quick web search found no company or app called Stellora, but this is not a trademark search. Before printing or registering, check the USPTO, EUIPO and WIPO registries (classes 9, 41, 42) and domain availability.

## Logo
A faceted four-point gold star inside an open aura ring, on a glass squircle. The ring is also a progress arc, so the mark reads as "time away from screens turns into a star".

| File | Use |
|---|---|
| `logo/stellora-icon-blue.svg`, `-charcoal.svg` | App icon, favicon source, avatar |
| `logo/stellora-icon-*-1024.png` | Raster app icon with transparent corners |
| `logo/stellora-lockup-horizontal-*.svg` | Headers, email, documents (on dark) |
| `logo/stellora-lockup-horizontal-on-light.svg` | Use on white or light backgrounds |
| `logo/stellora-lockup-stacked-*.svg` | Sign-in screen, splash, social |

Wordmarks are outlined to paths, so they render without the font installed.

## Type
Wordmark: Fraunces SemiBold. Tagline and UI labels: Bricolage Grotesque SemiBold, tracked +0.35em, uppercase. Kids UI display font in the app: Fredoka.

## Clear space and minimum size
Keep one star-width of clear space around the lockup. Minimum icon size 20px. Minimum horizontal lockup width 160px.

## Mascot concepts
`mascot-concepts/` holds six explored mascot directions (Zippy, Luna, Orbit, Sunny, Otto, Emblem) in blue and charcoal. Open `mascot-concepts.html` for the animated gallery. They are explorations and are not yet used in the app.

`stellora-brand-sheet.html` and `.png` show the full logo system on both themes.
